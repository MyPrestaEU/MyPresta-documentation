# Unique voucher for newsletter signup

## 1. Requirements & Compatibility

- **Supported PrestaShop Versions**: PrestaShop 1.5.x, 1.6.x, 1.7.x, 8.x, 9.x
- **PHP Compatibility**: PHP 5.6 - 8.5
- **Hosting Requirements**: Standard PHP extensions (cURL, JSON, OpenSSL) are typically sufficient. No special server configurations are usually needed beyond a standard PrestaShop hosting environment.

## 2. Complete Configuration Walkthrough (Every Setting Grouped by Screen)

### 2.1 Module Configuration Page (Back Office > Modules > Configure)

To access this, navigate to **Modules > Module Manager**, search for “Unique voucher for newsletter signup”, and click “Configure”.

This screen allows you to define the core behavior of the vouchers generated for newsletter signups.

- **What this setting does:** This section contains the primary settings for how your unique vouchers will be created and delivered.
- **Effect of changing this setting:** Adjusting these values directly impacts the discount amount, conditions, and validity of the vouchers your new newsletter subscribers receive.

**Settings & Options:**

1. **Voucher value (amount or percentage)**

   - **What this setting does:** This defines the discount amount or percentage that the unique voucher will provide.
   - **Effect of changing this setting:**
     - *If set to a specific amount (e.g., “10”):* The voucher will give a fixed monetary discount (e.g., €10 off).
     - *If set to a percentage (e.g., “15%”):* The voucher will give a percentage discount on the order total.
   - **Recommended value:** This depends on your pricing strategy. A common practice is 5-15% or a fixed amount like €5-€10 for initial purchases.
   - **Merchant scenario / example:** You want to offer a €5 discount to new subscribers. You would enter “5” here. If you prefer a 10% discount, you would enter “10%”.
2. **Minimum amount**

   - **What this setting does:** This sets the minimum order total (before shipping) required for the voucher to be valid.
   - **Effect of changing this setting:**
     - *If set to “0” or left empty:* The voucher can be used on any order, regardless of its total value.
     - *If set to a value (e.g., “50”):* The customer’s cart total must be at least €50 for the voucher to apply.
   - **Recommended value:** Set a minimum amount if you want to ensure a certain order value, or leave it at “0” if you want to encourage any purchase.
   - **Merchant scenario / example:** To prevent customers from using a €10 voucher on a €5 item, you might set a minimum amount of “30”.
3. **Voucher validity (days)**

   - **What this setting does:** This determines how many days the unique voucher will be valid from the moment it’s generated and sent to the customer.
   - **Effect of changing this setting:**
     - *If set to “0” or left empty:* The voucher will have no expiry date (not recommended, as it removes urgency).
     - *If set to a value (e.g., “30”):* The voucher will expire 30 days after the customer receives it.
   - **Recommended value:** 7, 14, or 30 days are common to create urgency without being too restrictive.
   - **Merchant scenario / example:** To encourage immediate purchases, you might set validity to “7” days, prompting customers to use the voucher quickly.
4. **Voucher description**

   - **What this setting does:** This text will appear as the description for the generated voucher in the customer’s cart and in the Back Office.
   - **Effect of changing this setting:** This helps customers understand what the voucher is for and provides context for your internal records.
   - **Recommended value:** “Newsletter Signup Discount” or “Welcome Voucher for Newsletter Subscribers”.
   - **Merchant scenario / example:** Entering “Welcome Discount for Newsletter Subscribers” clearly communicates the voucher’s purpose.
5. **Voucher prefix**

   - **What this setting does:** This allows you to add a custom prefix to the unique voucher codes generated by the module.
   - **Effect of changing this setting:**
     - *If left empty:* Voucher codes will be purely random (e.g., “ABCDEF123”).
     - *If set to a prefix (e.g., “NEWSLETTER-”):* Voucher codes will start with this prefix (e.g., “NEWSLETTER-ABCDEF123”). This helps you identify the source of the voucher.
   - **Recommended value:** “NEWSLETTER-” or “WELCOME-”.
   - **Merchant scenario / example:** Using “NEWSLETTER-” helps you quickly identify which vouchers came from newsletter signups when reviewing orders or statistics.
6. **Exclude products with specific categories**

   - **What this setting does:** This allows you to select specific product categories for which the voucher will NOT be applicable.
   - **Effect of changing this setting:**
     - *If no categories are selected:* The voucher can be used on any product in your store.
     - *If categories are selected (e.g., “Sale Items”, “Gift Cards”):* The voucher cannot be used to purchase products from these categories.
   - **Recommended value:** Use this if you have low-margin products, gift cards, or specific promotional items you don’t want discounted further.
   - **Merchant scenario / example:** You don’t want the voucher to apply to already discounted “Sale” items. You would select the “Sale” category here.
7. **Exclude products with specific manufacturers**

   - **What this setting does:** Similar to categories, this allows you to exclude products from specific manufacturers from being discounted by the voucher.
   - **Effect of changing this setting:**
     - *If no manufacturers are selected:* The voucher applies to all manufacturers.
     - *If manufacturers are selected (e.g., “Brand X”):* Products from “Brand X” cannot be purchased with the voucher.
   - **Recommended value:** Useful if you have exclusive brands or brands with strict pricing policies.
   - **Merchant scenario / example:** A particular high-end brand “Luxury Watches Inc.” does not allow any discounts. You would select “Luxury Watches Inc.” here.
8. **Exclude products with specific suppliers**

   - **What this setting does:** This allows you to exclude products from specific suppliers from being discounted by the voucher.
   - **Effect of changing this setting:**
     - *If no suppliers are selected:* The voucher applies to all suppliers.
     - *If suppliers are selected (e.g., “Supplier Y”):* Products from “Supplier Y” cannot be purchased with the voucher.
   - **Recommended value:** Less common for customer-facing promotions, but useful for internal inventory or specific supplier agreements.
   - **Merchant scenario / example:** You have a supplier “Wholesale Electronics” whose products are already at rock-bottom prices. You might exclude them from further discounts.
9. **Exclude products with specific attributes**

### 2.2 Dedicated Admin Screens & Controller Views

#### 2.2.1 Vouchers List (Back Office > Unique voucher for newsletter signup > Vouchers)

- **Screen Name & Menu Location:** After installing the module, a new menu item will appear in your PrestaShop Back Office, typically under **Catalog** or **Marketing**, named “Unique voucher for newsletter signup” or similar. Clicking on this will reveal a sub-menu item like “Vouchers”.
- **Available Actions & Settings:** This screen displays a list of all unique vouchers that have been generated by the module for newsletter signups.
  - **Grid / Management View:** You will see a table with columns such as:
    - **ID:** The unique identifier for the voucher entry.
    - **Customer:** The email address of the customer who received the voucher.
    - **Delivery date:** The date and time when the voucher was generated and sent.
    - **Voucher code:** The actual unique discount code.
    - **Actions:** Typically, you can view details, edit (though editing unique, auto-generated vouchers is less common), or delete entries.
- **Effect of changes:**
  - **Viewing:** Allows you to monitor the vouchers issued, see who received them, and track their codes. This is crucial for troubleshooting or customer service inquiries.
  - **Deleting:** Removing a voucher entry from this list will typically invalidate the corresponding voucher code, preventing its use. Use with caution.
- **Recommended workflow for daily store management:** Regularly check this list to monitor the effectiveness of your newsletter signup incentive. If a customer reports not receiving a voucher, you can verify its generation and code here. You can also manually delete expired or problematic vouchers if needed.

## 3. Merchant Troubleshooting & Frequently Asked Questions (FAQ)

**Q: My customers are signing up but not receiving the voucher email. What should I do?**
A:

1. **Check Spam Folders:** Advise customers to check their spam or junk mail folders.
2. **Verify Email Configuration:** Ensure your PrestaShop store’s email settings (Advanced Parameters > E-mail) are correctly configured and sending emails reliably. Test sending a simple email from PrestaShop.
3. **Check Module Configuration:** Go to **Modules > Module Manager > Unique voucher for newsletter signup > Configure**. Ensure all settings, especially the voucher value, are correctly set.
4. **Review Vouchers List:** Navigate to **Back Office > Unique voucher for newsletter signup > Vouchers**. Check if the voucher was actually generated and listed for the customer’s email. If it’s there, the issue is with email delivery; if not, the module might not be triggering correctly.
5. **Clear Cache:** Sometimes, clearing PrestaShop’s cache (Advanced Parameters > Performance > Clear cache) can resolve unexpected behavior.

**Q: The voucher code is generated, but it’s not applying the correct discount or has wrong conditions.**
A:

1. **Re-check Module Configuration:** Go to **Modules > Module Manager > Unique voucher for newsletter signup > Configure**. Carefully review all settings:
   - **Voucher value:** Is it the correct amount or percentage?
   - **Minimum amount:** Is the customer’s cart meeting this minimum?
   - **Exclusion settings:** Are there any categories, manufacturers, or specific products excluded that the customer is trying to purchase?
2. **Test with a New Subscription:** Create a new email address and subscribe to your newsletter to generate a fresh voucher. Test this new voucher yourself to replicate the issue.

**Q: Can I customize the email template that sends the voucher?**
A: This module typically integrates with PrestaShop’s default email system. The voucher code is usually inserted into an existing email template (like the newsletter confirmation email). To customize the email’s appearance or text, you would generally modify the relevant email template files in your theme’s `mails/` directory (e.g., `mails/en/newsletter.html` or `mails/en/newsletter.txt`). You might need a developer for advanced customization.

**Q: Does this module work with custom newsletter signup forms or pop-ups?**
A: This module is designed to work with PrestaShop’s standard newsletter subscription process. If your custom form or pop-up correctly integrates with PrestaShop’s core newsletter module (e.g., by calling the same subscription action), then this module should function correctly. If it uses a completely custom subscription method, it might require custom integration by a developer.

**Q: I have a multi-store setup. Does this module work for all my shops?**
A: Yes, the module should be compatible with multi-store environments. The configuration settings, including exclusions, should be manageable on a per-shop basis if PrestaShop’s configuration system is correctly utilized by the module. Always test thoroughly in a multi-store setup.
