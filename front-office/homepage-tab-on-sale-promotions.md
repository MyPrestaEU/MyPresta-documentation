# Homepage tab on sale (promotions)

## 1. Requirements & Compatibility
- **Supported PrestaShop Versions**: PrestaShop 1.7.x, 8.x, 9.x
- **PHP Compatibility**: PHP 7.1 - 8.5
- **Hosting Requirements**: Standard PHP extensions (cURL, JSON, OpenSSL).

## 2. Complete Configuration Walkthrough (Every Setting Grouped by Screen)

### 2.1 Module Configuration Page (Back Office > Modules > Configure)
This is the main and only configuration screen for the "Homepage tab on sale (promotions)" module. You can access it by navigating to **Modules > Module Manager** and searching for "Homepage tab on sale (promotions)", then clicking the "Configure" button.

#### Settings & Options:

-   **Number of products to be displayed**
    -   **What this setting does:** This controls how many products will be shown in the "On Sale" tab on your homepage. If you have more products on sale than this number, only the specified quantity will be displayed.
    -   **Effect of changing this setting:**
        -   *When set to a higher number (e.g., 10):* More sale products will be visible to your customers at once, potentially increasing the chance they find something they like. However, it might make the page longer and require more scrolling.
        -   *When set to a lower number (e.g., 4):* Fewer sale products will be shown, making the tab more concise and potentially faster to load. This can be good for a clean design but might hide some attractive deals.
    -   **Recommended value:** Start with a value between **8 and 12**. This is a good balance for most themes, providing enough choice without overwhelming the customer.
    -   **Merchant scenario / example:** If you have many products on sale and want to highlight variety, you might set it to 12. If you prefer a minimalist look or only have a few key promotions, setting it to 6 might be better.

## 4. Complete Configuration Walkthrough (Every Setting Grouped by Screen)

### 4.1 Module Configuration Page (Back Office > Modules > Configure)
This is the primary and only configuration screen for the "Homepage tab on sale (promotions)" module. You can access it by going to **Modules > Module Manager**, searching for "Homepage tab on sale (promotions)", and then clicking the "Configure" button.

#### Settings & Options:

-   **Number of products to be displayed**
    -   **What this setting does:** This setting determines the maximum number of discounted products that will be shown within the "On Sale" tab on your store's homepage. If you have more products currently on sale than the number you specify here, the module will only display this set quantity.
    -   **Effect of changing this setting:**
        -   *When enabled / set to a higher number (e.g., 12):* Your customers will see a larger selection of promotional products when they click the "On Sale" tab. This can be beneficial for stores with many active discounts, offering more choice and potentially increasing the likelihood of a purchase. However, displaying too many products might make the page longer and could slightly increase loading time.
        -   *When disabled / set to a lower number (e.g., 4):* Fewer sale products will be visible. This can create a cleaner, more focused display, which might be preferred if you have only a few key promotions or want to keep your homepage very concise. It can also lead to faster page loading.
    -   **Recommended value:** A good starting point is **8 to 10 products**. This provides a decent selection without overwhelming the customer or making the page excessively long. You can adjust this based on your average number of sale items and your theme's layout.
    -   **Merchant scenario / example:**
        -   *Scenario 1 (Large Inventory, Frequent Sales):* You run weekly promotions with 50+ products on sale. You might set this to **12** to give customers a good overview of the variety of deals available directly from the homepage.
        -   *Scenario 2 (Boutique Store, Few Key Promotions):* You typically have only 3-5 high-value items on sale at any given time. You might set this to **6** to ensure all your key promotions are visible without empty spaces or unnecessary scrolling.
