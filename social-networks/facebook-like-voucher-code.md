# Facebook like voucher code

## 1. Requirements & Compatibility
- **Supported PrestaShop Versions**: PrestaShop 1.4.x, 1.5.x, 1.6.x, 1.7.x
- **PHP Compatibility**: PHP 5.6 - 8.5
- **Hosting Requirements**: Standard PHP extensions (cURL, JSON, OpenSSL) are typically required for PrestaShop itself and any module interacting with external APIs like Facebook.

## 2. Complete Configuration Walkthrough (Every Setting Grouped by Screen)

### 2.1 Module Configuration Page (Back Office > Modules > Configure)
This is the main configuration screen for the "Facebook like voucher code" module, accessible after installation by clicking the "Configure" button. Here you will define how the Facebook Like button appears and how the voucher codes are generated.

#### **Facebook Page URL**
- **What this setting does:** This is the most crucial setting. It tells the module which Facebook page your customers should "Like" to receive the voucher.
- **Effect of changing this setting:**
  - *When set to your Facebook page URL (e.g., `https://www.facebook.com/MyPresta.eu`):* The "Like" button on your store will link directly to and track likes for this specific Facebook page.
  - *When left empty or set incorrectly:* The "Like" button will not function correctly, or it might link to a non-existent page, preventing customers from receiving vouchers.
- **Recommended value:** Enter the full URL of your official Facebook business page.
- **Merchant scenario / example:** If your Facebook page is `https://www.facebook.com/myawesomestore`, you would enter that exact URL here.

#### **Voucher Code Prefix**
- **What this setting does:** This allows you to add a custom prefix to all voucher codes generated by this module. This helps you easily identify which vouchers came from your Facebook promotion.
- **Effect of changing this setting:**
  - *When set to "FB":* All generated voucher codes will start with "FB" (e.g., FB123456).
  - *When left empty:* Voucher codes will be generated without a specific prefix, making them harder to distinguish from other voucher types.
- **Recommended value:** A short, memorable prefix like "FB", "LIKE", or "SOCIAL".
- **Merchant scenario / example:** Using "FB" allows you to quickly filter your voucher codes in the PrestaShop Back Office to see how many were generated through this module.

#### **Voucher Code Value**
- **What this setting does:** Defines the discount value of the voucher code. This can be a fixed amount or a percentage.
- **Effect of changing this setting:**
  - *When set to "10" and "Percentage":* Customers receive a 10% discount.
  - *When set to "5" and "Amount":* Customers receive a $5 (or your default currency) discount.
- **Recommended value:** A value that is attractive enough to encourage a purchase but also sustainable for your profit margins (e.g., 5, 10, 15).
- **Merchant scenario / example:** Offering "10" and "Percentage" for a 10% discount is a common and effective strategy to encourage first-time buyers.

#### **Voucher Code Type**
- **What this setting does:** Determines whether the voucher code offers a percentage discount or a fixed amount discount.
- **Effect of changing this setting:**
  - *When set to "Percentage":* The "Voucher Code Value" will be interpreted as a percentage (e.g., 10% off).
  - *When set to "Amount":* The "Voucher Code Value" will be interpreted as a fixed monetary amount (e.g., $10 off).
- **Recommended value:** "Percentage" is often more appealing as it scales with the order value, but "Amount" can be effective for lower-priced items or specific promotions.
- **Merchant scenario / example:** If you want to give a flat $5 discount regardless of order size, choose "Amount". If you want to give a discount that increases with the order value, choose "Percentage".

#### **Voucher Code Minimum Amount**
- **What this setting does:** Sets a minimum order total (before shipping) that a customer must reach to be able to use the voucher code.
- **Effect of changing this setting:**
  - *When set to "50":* The voucher can only be used if the cart total is $50 or more.
  - *When left empty or set to "0":* The voucher can be used on any order amount.
- **Recommended value:** A value that encourages customers to add more items to their cart, increasing average order value (e.g., 25, 50).
- **Merchant scenario / example:** If your average order value is $40, setting a minimum amount of $50 for a 10% voucher encourages customers to add an extra item to qualify for the discount.

#### **Voucher Code Expiration Days**
- **What this setting does:** Defines how many days the generated voucher code will be valid from the moment it's issued.
- **Effect of changing this setting:**
  - *When set to "7":* The voucher code will expire 7 days after the customer receives it.
  - *When left empty or set to "0":* The voucher code will have no expiration date (or a very long default one set by PrestaShop).
- **Recommended value:** A reasonable timeframe to create urgency without being too restrictive (e.g., 7, 14, 30 days).
- **Merchant scenario / example:** Setting it to "7" days encourages customers to make a purchase sooner rather than later, preventing them from forgetting about the voucher.

#### **Voucher Code Description**
- **What this setting does:** Allows you to add a custom description to the generated voucher code in your PrestaShop Back Office. This helps you track the purpose of the voucher.
- **Effect of changing this setting:**
  - *When set to "Facebook Like Promotion":* This description will be visible when you view the voucher details in your PrestaShop Back Office, making it clear where the voucher originated.
  - *When left empty:* The voucher will have no specific description, making it harder to identify its source.
- **Recommended value:** A clear, concise description like "Facebook Like Voucher" or "Social Media Promo".
- **Merchant scenario / example:** Using "Facebook Like Promotion" helps your customer service team understand the context of the voucher if a customer has questions about it.

#### **Display Block In**
- **What this setting does:** Determines where the Facebook "Like" button block will appear on your store's front office.
- **Effect of changing this setting:**
  - *When "Header" is selected:* The block appears at the top of every page.
  - *When "Left Column" is selected:* The block appears in the left sidebar.
  - *When "Right Column" is selected:* The block appears in the right sidebar.
  - *When "Product Page" is selected:* The block appears on individual product pages.
  - *When "Footer" is selected:* The block appears at the bottom of every page.
- **Recommended value:** "Header" or "Product Page" for maximum visibility and impact, or "Left/Right Column" if you prefer a less intrusive placement.
- **Merchant scenario / example:** Placing it in the "Header" ensures every visitor sees it. Placing it on the "Product Page" targets customers who are already interested in making a purchase.

#### **Voucher Code Popup Message**
- **What this setting does:** This is the message that customers will see in the popup window along with their voucher code after they "Like" your Facebook page.
- **Effect of changing this setting:**
  - *When set to "Thank you for liking us! Here is your discount code: {voucher_code}":* The customer will see this exact message with their unique code inserted.
  - *When left empty:* The customer might only see the code without any accompanying text, which could be confusing.
- **Recommended value:** A friendly, clear message that thanks the customer and explicitly states that the code is for a discount. **Always include `{voucher_code}`** so the actual code is displayed.
- **Merchant scenario / example:** "Thank you for joining our community! Here's a special treat for you: {voucher_code}. Enjoy your shopping!"

#### **Voucher Code Popup Title**
- **What this setting does:** Sets the title of the popup window that displays the voucher code.
- **Effect of changing this setting:**
  - *When set to "Your Exclusive Discount!":* This title will appear at the top of the popup window.
  - *When left empty:* The popup might have a generic or no title, which is less professional.
- **Recommended value:** A catchy and clear title that reinforces the reward (e.g., "Your Free Voucher!", "Thank You for Liking Us!").
- **Merchant scenario / example:** "Your Exclusive Discount!" immediately tells the customer they've received a valuable reward.
